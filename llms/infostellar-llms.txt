# Infostellar

> Infostellar operates StellarStation, a cloud ground-station-as-a-service (GSaaS) platform that aggregates partner and operator antennas into a shared global network. Satellite operators use its public gRPC API to discover and reserve upcoming passes, schedule and cancel plans, manage TLE orbital data, and stream live telemetry and commands to and from spacecraft.

## APIs

- [StellarStation API (gRPC)](https://github.com/infostellarinc/stellarstation-api): Public Protocol Buffers / gRPC API at api.stellarstation.com:443. Two services — StellarStationService (satellite operators) and GroundStationService (antenna operators).

## Specs

- [stellarstation.proto](grpc/infostellar-stellarstation.proto): StellarStationService — ListPlans, CancelPlan, ListUpcomingAvailablePasses, OpenSatelliteStream, ReservePass, AddTle, GetTle, SetTleSource, SetPlanMetadata.
- [groundstation.proto](grpc/infostellar-groundstation.proto): GroundStationService — AddUnavailabilityWindow, DeleteUnavailabilityWindow, ListUnavailabilityWindows, ListPlans, CancelPlan, GetCurrentPlan, OpenGroundStationStream.
- [orbit.proto](grpc/infostellar-orbit.proto), [radio.proto](grpc/infostellar-radio.proto), [antenna.proto](grpc/infostellar-antenna.proto), [monitoring.proto](grpc/infostellar-monitoring.proto), [transport.proto](grpc/infostellar-transport.proto), [common.proto](grpc/infostellar-common.proto): supporting definitions.
